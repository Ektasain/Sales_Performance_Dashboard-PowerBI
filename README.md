# 📊 Sales Performance Dashboard | Power BI

## 📌 Project Overview

This project analyzes sales performance using the Sample Superstore dataset. The objective is to transform raw sales data into meaningful business insights using Python, Power BI, and DAX.

The interactive dashboard provides insights into sales trends, profit, customer behavior, product performance, regions, and categories.

---

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify monthly sales trends.
- Compare sales across different regions.
- Analyze category and customer segment performance.
- Identify top-performing products and customers.
- Generate actionable business insights.
